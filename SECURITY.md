# Security

This is an early-development scaffold, with no supported production scanner yet.

Report vulnerabilities privately through [GitHub's security advisory reporting](https://github.com/raluonyiuke/qa11y/security/advisories/new). If private reporting is unavailable, open an issue asking the maintainer for a private reporting channel without disclosing exploit details or sensitive data.

Do not attach credentials, session cookies, private URLs, or unredacted scan evidence to public issues. Use local synthetic pages to reproduce bugs where possible.
